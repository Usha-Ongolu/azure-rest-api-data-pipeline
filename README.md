# Azure REST API Data Engineering Pipeline

## Overview

An end-to-end Azure data engineering project demonstrating the
ingestion, transformation, storage, and visualization of sales data.

The solution follows a modern cloud data engineering architecture
using Azure Data Factory, Azure Blob Storage, Azure SQL Database,
Python, SQL, and Power BI.
